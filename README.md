# Klasstavla – Interaktiv klassrumstavla

En interaktiv klassrumshanteringsapplikation med widgets, live-rum och presentationsverktyg för moderna lärare.

## Funktioner

- **Widgets**: Timer, klocka, omröstning, randomizer, ljudnivå, musik, bilder, text, arbetsmarkörer, trafikljus, schema, presentation, lektionsframsteg, gruppindelning, poängtavla, handsräckning, YouTube, QR-kod, steg-för-steg instruktioner och kritiskt tänkande-kort
- **Live-rum**: Lärare kan skapa rum för realtidsinteraktion med elever
- **Bakgrundsanpassning**: Välj mellan förvalda bakgrunder, URL-inmatning eller filuppladdning
- **Skärmhantering**: Spara och ladda olika klassrumskonfigurationer
- **Mediabibliotek**: Hybrid bild-/symbolbibliotek med Pexels-foton och ARASAAC-symboler
- **Lektionshantering**: Skapa, hantera och leverera lektioner med återanvändbara skärmar

## Teknik

- **Frontend**: Vanilla JavaScript
- **Styling**: CSS med custom properties
- **Server**: Node.js HTTP + WebSocket
- **Lagring**: LocalStorage för persistens
- **Realtid**: WebSocket för synkronisering mellan enheter
